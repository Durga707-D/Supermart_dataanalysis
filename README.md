# Supermarket Sales Analysis Dashboard

## Project Overview
This project focuses on analysing supermarket sales data using Microsoft Excel. The aim is to understand sales performance, identify top-performing product categories, compare outlet performance, and discover useful business insights through an interactive dashboard.

## Objectives
The project covers four main objectives:
1. **Overall Sales Performance**
   - Calculate total sales.
   - Calculate average sales per record.
   - Analyse average item visibility.
2. **Product Category and Sales Comparison**
   - Identify the highest- and lowest-selling product categories.
   - Analyse the contribution of the top four categories.
   - Compare sales across outlet types.
3. **Outlet Performance and Sales Relationships**
   - Compare Low Fat and Regular product sales across outlets.
   - Analyse the relationship between item visibility and sales.
   - Compare category-wise sales across outlet types.
4. **Statistical Analysis of Sales**
   - Calculate average, median, minimum, and maximum sales.
   - Calculate standard deviation and variance.
   - Identify unusual sales records using the IQR method.
   - Compare average sales by category, outlet type, and outlet location.

## Key Findings

- **Total Sales:** 1,201,681.49
- **Average Sales:** 140.99
- **Median Sales:** 143.01
- **Highest Sales Category:** Fruits and Vegetables
- **Lowest Sales Category:** Seafood
- **Top Four Categories Contribution:** 50.60%
- **Highest Performing Outlet Type:** Supermarket Type1
- **Standard Deviation:** 62.28
- **Variance:** 3,878.18
- **Outliers:** No unusually high or low records identified using the IQR method.
